Política de privacidad

Aplicación «El Archivero del Tiempo» · Última actualización: 17 de noviembre de 2026

Quién la usa

La aplicación la usa únicamente el responsable del canal de YouTube El Archivero del Tiempo, para gestionar su propio canal. No está abierta a otros usuarios.

Qué datos de Google usa

Con la autorización del titular del canal, la aplicación usa la API de datos de YouTube con estos permisos:

  • youtube.upload: subir vídeos al canal propio.
  • youtube.force-ssl: gestionar el canal propio (título, descripción, fecha de publicación, miniatura, subtítulos, listas de reproducción y datos del canal).

Solo accede a la información del canal propio que hace falta para esas tareas. No lee, recoge ni trata datos de espectadores ni de otros usuarios de YouTube.

Dónde se guardan

El token de acceso se guarda solo en el ordenador del responsable del canal. No se envía a ningún servidor propio ni a terceros, no se vende ni se comparte, y no se usa para publicidad.

Cómo revocar el acceso

El titular puede retirar el permiso en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, la aplicación deja de tener acceso y el token guardado deja de funcionar.

Servicios de Google

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Al usar la API de YouTube se aplican también las Condiciones del servicio de YouTube y la Política de privacidad de Google.
