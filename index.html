El Archivero del Tiempo

Cada historia empieza con un papel rescatado del archivo.

El Archivero del Tiempo es un canal de YouTube de historia documental en español. Cada vídeo se construye sobre un documento real (una carta, un acta, un diario) que se lee, se contrasta con otras fuentes y recibe un veredicto de fiabilidad de 1 a 5 sellos.

Canal de YouTube: youtube.com/@ElArchiveroDelTiempo

La aplicación «El Archivero del Tiempo»

El canal usa una pequeña aplicación propia que se ejecuta en el ordenador del responsable del canal. Sirve para una sola cosa: subir y programar los vídeos del propio canal mediante la API de datos de YouTube (YouTube Data API v3), y añadirles miniatura, subtítulos y listas de reproducción. No es un servicio abierto al público ni accede a cuentas de otras personas.
